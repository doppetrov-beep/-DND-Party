# ⚔ Сбор пати — D&D-календарь для друзей

Отдельный сайт для планирования совместных D&D-игр с учётом разных часовых поясов. Здесь **нет личного графика смен, зарплаты или заметок** из другого календаря.

**Сайт:** https://doppetrov-beep.github.io/-DND-Party/

## Как пользоваться

1. Один игрок открывает сайт, вводит ник и создаёт комнату.
2. Нажимает **«Скопировать приглашение»** и отправляет одну ссылку всем друзьям.
3. Каждый заходит со своего устройства, указывает ник и отмечает удобные дни и часы в своём часовом поясе.
4. Поля «Начало» и «Конец» вводятся **без даты**: её выбирают сверху. Можно сразу заполнить 2, 3, 4, 5 или 7 дней подряд.
5. Ниже появляются лучшие временные окна, в которые могут собраться все либо максимальное число игроков.

Максимум 12 участников на комнату, варианты на ближайшие 21 день, длительность игры 2, 3 либо 4 часа. Обновление примерно каждые 20 секунд и по кнопке.

### База данных

Используется существующий проект Supabase **DND-Party-Scheduler** (EU Frankfurt, Free). В `config.js` находится **только публичный publishable key**, не секретный API-ключ.

В Supabase включите **Authentication → Providers → Anonymous Sign-Ins** (если не включено):
https://supabase.com/dashboard/project/yxpkmbckediniyuomvbs/auth/providers

Схема `schema.sql` нужна только для создания нового проекта с нуля; на действующей базе уже развёрнута. **Не запускайте этот файл повторно без необходимости.**

### Приватность и ограничения

- Секретная ссылка даёт доступ к комнате: делитесь ею только с участниками.
- «Регистрация» только по нику, без подтверждения личности. Новый браузер/устройство может создать другого игрока с тем же ником.
- В отличие от личного офлайн-календаря, для синхронизации ответов здесь **нужен интернет**.
- Бесплатный Supabase может приостановить проект за низкую активность. Подробнее: https://supabase.com/docs/guides/platform/free-project-pausing
- После переноса на новый домен участникам ранее созданной комнаты может потребоваться **зайти снова**, потому что анонимные сессии сохраняются отдельно для каждого домена. Это создаст новый профиль, но не удалит старые записи. При необходимости создайте новую комнату для чистого списка участников.
- Сайт рассчитан на использование небольшой группой друзей, а не как публичный сервис регистрации.

## Файлы

- `index.html` — интерфейс
- `app.js` — комнаты, время и подбор пересечений
- `style.css` — стили
- `config.js` — публичные данные подключения Supabase
- `schema.sql` — SQL-структура и RLS
- `.github/workflows/deploy.yml` — публикация GitHub Pages

## Публикация

GitHub Actions публикует ветку `main` на GitHub Pages. Если публикация недоступна, проверьте **Settings → Pages → Build and deployment → GitHub Actions**.
